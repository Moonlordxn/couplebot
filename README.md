# CouplePet — Мир для двоих

Telegram-бот для личных питомцев и совместного выращивания одного семейного питомца двумя владельцами.

## Установка

1. Используйте Python 3.10 или новее.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Скопируйте `env.example` в `.env`.
4. Заполните `BOT_TOKEN`, `OWNER_ID`, `REQUIRED_CHANNEL`.
5. Добавьте бота администратором в канал `@couplepets_updates`, чтобы Telegram разрешал проверять подписку через `getChatMember`.
6. Сделайте резервную копию текущего SQLite-файла базы данных.
7. Запустите: `python main.py`.

`DATABASE_PATH` может указывать на существующую базу. При старте выполняются повторяемые миграции, которые не удаляют питомцев и историю.

## Режимы питомцев

- Личный питомец создаётся командой `/create ИМЯ [вид]` в личном чате. Он остаётся личным и не может быть присоединён к семье.
- Семья создаётся через `/family`. Владелец получает код и ссылку вида `https://t.me/<bot>?start=family_<CODE>`.
- Приглашённый подтверждает, что хочет выращивать питомца именно с указанным человеком. Затем первый владелец отдельно подтверждает конкретного участника.
- После подтверждения обоих владельцев в меню семьи можно создать нового общего питомца.
- Семейный питомец доступен обоим владельцам в личных чатах. В группах его подключают командой `/connect_family`, которую отправляет один из владельцев.
- К одной семье можно подключить несколько групп. Все интерфейсы используют одну запись питомца.
- В группе все участники могут просматривать питомца, но команды и кнопки ухода доступны только двум владельцам.

## Основные команды

- `/start` — запуск бота; также обрабатывает семейную реферальную ссылку.
- `/profile` — личный профиль.
- `/family` — семейный профиль, код и ссылка приглашения.
- `/join_family CODE` — начать вступление по коду.
- `/create NAME [species]` — создать личного питомца.
- `/status` — открыть основной питомец (семейный, если он есть).
- `/solo_status` — открыть личного питомца, если у пользователя также есть семья.
- `/feed`, `/play`, `/wash`, `/sleep` — уход за выбранным основным питомцем.
- `/solo_feed`, `/solo_play`, `/solo_wash`, `/solo_sleep` — уход за личным питомцем.
- `/connect_family` — подключить семейного питомца к текущей группе.
- `/release_pet` — запросить расформирование семьи после подтверждения.
- `/admin` — административная панель владельца.

## Автоматические потребности

Потребности рассчитываются по отдельным временным меткам кормления, игры, мытья и сна. Голод достигает порога напоминания примерно через два часа. Напоминания объединяются, имеют cooldown и отправляются в подключённые группы и личные чаты владельцев, которые запускали бота.

## Подписка

В личных чатах требуется подписка на `REQUIRED_CHANNEL`. В группах проверка не применяется. Если бот не является администратором канала или не имеет возможности проверить участника, доступ в личном чате будет закрыт до успешной проверки.

## Админ-панель

Доступна только Telegram ID из `OWNER_ID`:

- статистика за сутки, неделю и всё время;
- график уникальных активных пользователей по дням;
- список всех семей с постраничной навигацией и карточкой семьи;
- поиск пользователя по Telegram ID или username;
- анонимизация профиля пользователя с архивированием связанных питомцев/семьи;
- архивирование семьи по ID с уведомлением обоих участников;
- блокировка, разблокировка, выдача монет и Premium;
- журнал административных действий.

Удаление профиля реализовано как анонимизация: личные данные профиля скрываются, коллекция удаляется, личные питомцы и связанные семьи архивируются, а игровая история питомцев сохраняется.

## Главное меню

Главное меню содержит профиль, семью, питомца и раздел «Как играть». Магазин кейсов, покупки кейсов и кнопка коллекции удалены из пользовательского интерфейса. Данные старых коллекций в базе не удаляются.

При создании семьи, если у пользователя есть активный личный питомец, бот сначала просит подтвердить отпускание на волю. Питомец архивируется, а его запись и история сохраняются. После создания общего питомца второй владелец получает личное уведомление; если он ещё не запускал бота, ошибка доставки не мешает созданию питомца.

## Важные замечания перед развёртыванием

- Никогда не отправляйте `BOT_TOKEN` в архиве или сообщениях.
- Перед обновлением сделайте резервную копию базы данных.
- Проверьте, что оба владельца нажали Start в личном чате: Telegram не позволяет боту первым начать личную переписку.
- Для проверки подписки бот должен быть администратором канала.
- Сначала протестируйте обновление на копии базы и двух тестовых Telegram-аккаунтах.
